Computer use

Put an agent at a real computer — one key, one command, outbound-only.

Why it exists

Some work only exists inside installed software — Xactimate above all. Web Access cannot reach a desktop application, so Atmosphere puts an agent at the machine itself.

Setup

Two things, and you are running:

  1. One API key — connect your Anthropic API key in Settings. This key is how the agent sees; it is a setup step, not how Atmosphere bills you.
  2. One command — run the Atmosphere agent on the computer to be operated. macOS, Windows, and Linux are all supported.

How the connection works

The machine connects outward over a single outbound-only WebSocket — screenshots go up, clicks and keystrokes come back. No inbound port is ever opened on the machine being operated, so there is nothing on it to scan, probe, or forward.

What the agent can do

It sees the screen and operates it: the mouse, the keyboard, the software you already own. Sessions are recorded in the audit trail like every other run, so you can replay exactly what was done on the machine and when.

Run the agent on the machine that owns the work — the estimating workstation, not a personal laptop. What it operates is what it can see.
