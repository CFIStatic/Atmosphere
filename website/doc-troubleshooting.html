Troubleshooting

When something misbehaves — sign-in, join codes, stuck runs, connections, billing — start here.

Signing in

My password isn't working

Use Forgot password on the sign-in screen. A reset link arrives by email, and the token exchange happens on the server — if the link has expired, request a fresh one rather than retrying it.

My PIN doesn't work on this phone

That is the PIN doing its job: it is bound to the single device you enrolled it on. On any other device, sign in with your password, then enroll a PIN there too if you want one.

Organizations and join codes

The join code is rejected

Codes are exact — check for a mistyped character first. If it still fails, the code may have been rotated; ask whoever runs your organization to read it to you from their dashboard.

I created a second organization by mistake

Sign out, sign back in, and join the right organization with its code. Ask us via the contact page to remove the empty one.

Runs and agents

A run failed or seems stuck

Open the run in the audit trail and replay it — the record shows the exact step where it stopped and what the agent saw there. Most failures are the outside system changing (a portal login page moved, a session expired); reconnect the site and run it again.

The Verifier flagged something

Working as intended. The Verifier corrects only what is safe and asks about everything else — answer its question and the run completes. It never guesses on your behalf.

Web Access can't reach a site

Portals change. If a connected site stops working, re-connect it (credentials may have rotated or the portal added a verification step). The run record shows precisely where access stopped.

Computer use

The agent won't connect to my machine

Three things to check, in order:

  1. The agent command is running on the machine, and the machine is awake.
  2. The network allows outbound HTTPS/WebSocket traffic — the agent only dials out, so no inbound port or port-forward is ever needed.
  3. The Anthropic API key in Settings is valid — it is how the agent sees the screen.

Billing

Work is paused

Almost always an empty credit balance — Atmosphere never spends money you haven't loaded. Buy a pack (or turn on auto-reload in Settings → Billing so this stops happening), and paused runs resume; nothing in your record is lost while paused. If the balance isn't the problem, check that your subscription payment method is current.

A charge looks wrong

Every token is metered from the model provider's own response and lands in the append-only ledger — read it by run, by agent, and by platform. If the ledger and your invoice disagree, that is a bug: send us both.

Still stuck?

Write to us with the run ID from the audit trail if the problem involves a run — it lets us replay exactly what you saw, which is usually the whole diagnosis.
