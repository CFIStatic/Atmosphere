Security

The shape of the system is the security model

Access control at Atmosphere isn't a policy we promise to enforce in application code. It's architecture: the database, the cookie jar, and the network direction do the enforcing — and they can't be talked out of it.

ARCHITECTURE PRINCIPLES VERIFICATION
Architecture

Every request wears the caller's identity

The browser talks to our application. The application talks to the database as the signed-in person — never with a privileged bypass — so access rules in the database decide what every query can see.

│  Browser  │ ─────────────────────▶ │  Application  │ ──never a privileged───▶ │     Database     │

The frontend holds no tokens. The database enforces access. Devices in the field only ever dial out.

Principles

Six things that are true by construction

Each of these holds because of where the data lives and which direction the wires point — not because a code path remembered to check.

hash

Passwords are never stored by us

Sign-in stores only a one-way hash. The app never sees or persists a plaintext password.

httpOnly

Tokens never touch browser JavaScript

The application exchanges credentials for a session and puts it in httpOnly cookies. Page JavaScript holds nothing worth stealing, which mitigates token theft via XSS.

access

The database is the source of truth

Every query runs as the signed-in person — never with a privileged bypass. Who can see what is decided at the database, where another organization's data simply doesn't exist for you.

device

PIN sign-in is bound to one device

The optional 4-digit PIN enrolls a single device, and the server keeps only hashes — no secret and no session token. A stolen PIN without the enrolled device is worthless.

server-side

Password recovery happens on the server

Reset links arrive by email, and the token exchange is performed on the server — so no session token is ever exposed to page JavaScript, even during recovery.

outbound

Devices dial out, never in

A phone, tablet, or office computer only ever connects outbound. No inbound port is opened on a machine in the field.

Verification

Trust is a workflow, not a checkbox

Work the AI does in someone else's system is checked afterwards by a second agent that goes and looks — in a read-only browser that cannot change anything. And everything every agent does lands in one append-only audit trail your organization can replay step by step.
