Platform

Four platforms. One record.

A job moves through your company in stages, and so does Atmosphere: win it, run it, capture it on site, and account for it. Each platform stands on its own — and all four write to the same record, check their work the same way, and get better from the same scores.

Shared foundation

What all four stand on

The parts that would be worth building once even if you only ever bought one platform — how agents reach your systems, how their work gets checked, and how the whole thing improves.

Access

It goes where the work already is

Connect a carrier portal, a supplier site, or a builder platform once, and Atmosphere signs in to pull data out or enter data in — recording every step, so a finished run reads back like a receipt.

Some work only exists inside installed software. Run the agent on any computer — macOS, Windows, or Linux — and it sees the screen and operates it, in the software you already own.

ConnectOnce per site — portal, supplier, builder platform
OperatesmacOS · Windows · Linux
NeedsOne API key · one command
LinkOutbound-only WebSocket — no inbound port
Trust

No agent grades its own work

After a run finishes, a second agent re-opens the work in a browser that cannot change anything and confirms it against the task as it was originally written. What is safe to correct, it corrects; what it is unsure of, it brings to you.

Every unit of work every agent performed lands in one append-only record you can replay step by step — no matter which platform it came from.

OpensRead-only browser — cannot change anything
ConfirmsThe work, against the task as written
ReplaysAny run, step by step
KeepsAppend-only — history is never rewritten
Data

One record underneath all four

Customers, properties, leads, jobs and their timeline — plus our own backups and a verbatim copy of the data that currently lives only inside other companies' software. Agent Memory layers the operational detail on top: the tasks under a job, the crew on it, and the work logged against it.

HoldsCustomers · properties · leads · jobs · timeline
MirrorsA verbatim copy of data held in other software
LogsTasks · crew · work entries — append-only
Learning

It gets measurably better at your work

Every run — a drafted scope, a built estimate, extracted document fields, a customer update — is scored, and the routing policy improves from those scores. Not a model trained on the internet's idea of restoration: a routing layer tuned by the outcomes of your organization's own runs.
