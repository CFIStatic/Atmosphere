Billing

$199.99 per user per month for the seat, plus prepaid usage at five times model cost.

Seats

The seat buys platform access for one user. It does not include usage credits.

PlanPriceNotes
Pro$199.99 / user / monthNo included usage
EnterpriseCustom25 seats minimum · contact sales

Sales, Operations, Field, and Manager use this same seat price.

Usage rates (5× cost)

Atmosphere pays the “We pay” column. Customers are charged five times that amount. One credit is one dollar of sell-side usage.

ModelWe pay (in / out per MTok)You pay (in / out per MTok)
Apex$10 / $50$50 / $250
Pro$5 / $25$25 / $125
Core$3 / $15$15 / $75
Lite$1 / $5$5 / $25

Cache writes, cache reads, and batch requests use the same 5× markup on the underlying cost multipliers.

Credits: prepaid, always

Usage is prepaid. You buy credits and agents draw the balance down as they work. Nothing runs on an unpaid balance.

Credits come in packs from $10 to $1,000; larger packs carry a volume bonus ($100 buys $103 of usage; $1,000 buys $1,075).

Auto-reload or manual reload

In Settings → Billing you choose how the balance stays topped up:

  • Auto-reload on — set a threshold and an amount; defaults are a $25 reload when the balance falls under $5.
  • Auto-reload off (manual) — every purchase is one you made. At zero, new runs pause until you top up.

An organization-level monthly spend cap is available either way.

How usage is counted

Token counts come from the model provider’s own response, never from the browser. Every grant, charge, and adjustment lands in an append-only ledger.
