Work Verification

Service work runs on word against word. This ends it.

Disputed job days, unpaid invoices, work questioned months later from a photo folder — all the same failure: no record. Field Capture films the work; the Evidence Platform holds the proof — two short videos a day.

01

Film it like this

A shot list built from the job's own scope: prove the address, walk the work, film the exclusions untouched.

02

Checked at the door

GPS on the site, clock on the day, hash sealed at arrival. A clip filmed two miles away is flagged before anybody watches it.

03

Read by the assistant

AI reads the footage against the agreed scope and writes the narrated report — coverage computed, never claimed.

04

Held and handed over

An append-only chain of custody, shared account-to-account with whoever needs to sign off on the work.

Security

Built for evidence that has to hold up

Passwords are never stored by us. Tokens never touch browser JavaScript. The database — not application code — decides who sees what. The shape of the system is the security model.

auth

Your password isn't ours to lose

We never see it and never store it.

httpOnly

A hijacked page isn't a hijacked account

No token this site loads can be read by its own JavaScript.

access

Another contractor's jobs don't exist for you

The database enforces that, not our code.
